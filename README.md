YouTube Trending Videos Analysis

Project Overview

This project analyzes YouTube Trending Videos data to uncover patterns behind popular content. Using Python and data analysis techniques, the dataset was explored to identify trending categories, high-performing channels, engagement metrics, and content publishing trends.

Objectives

- Analyze trending video performance on YouTube.
- Identify the most popular content categories.
- Study viewer engagement through views, likes, comments, and dislikes.
- Discover top-performing channels and videos.
- Examine publishing and trending patterns.

Dataset

The dataset contains information about YouTube trending videos, including:

- Video Title
- Channel Title
- Category ID
- Publish Time
- Trending Date
- Views
- Likes
- Dislikes
- Comment Count

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Data Cleaning

- Handled missing values
- Converted date and time columns
- Removed invalid records
- Created additional features for analysis

Exploratory Data Analysis (EDA)

The following analyses were performed:

- Most Popular Video Categories
- Top Trending Channels
- Views vs Likes Analysis
- Likes vs Comments Relationship
- Publishing Time Patterns
- Trending Duration Analysis
- Country-wise Trending Comparison
- Engagement Metrics Evaluation

Key Insights

- Entertainment and Music categories dominate trending content.
- Videos with higher engagement often receive more views.
- Certain channels consistently appear in trending lists.
- Publishing timing can influence trending performance.
- Viewer interaction strongly correlates with video popularity.
